# Fonts

`latinmodern-math.woff2` is Latin Modern Math 1.959 by GUST e-foundry, the OpenType math font of
LaTeX, converted unchanged from `latinmodern-math.otf` on CTAN (fonts/lm-math) to WOFF2 with
fontTools. It is distributed under the GUST Font License (http://tug.org/fonts/licenses/GUST-FONT-LICENSE.txt),
which allows redistribution. `assets/site/style.css` uses it for all MathML formulas.
